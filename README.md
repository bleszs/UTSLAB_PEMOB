Quizora Quest 🎓
Quizora Quest adalah aplikasi edukasi berbasis Flutter yang mengajak pengguna menyelesaikan puzzle dan kuis melalui beberapa misi. Pengguna dapat memilih avatar dan mode permainan, mengerjakan tantangan, menggunakan petunjuk, melihat hasil, serta mempelajari kembali pembahasan jawaban.

Deskripsi
Quizora Quest merupakan aplikasi kuis edukatif dengan pendekatan permainan puzzle. Pengguna menyelesaikan misi bertema pemecahan masalah, menyusun langkah, memahami konsep pemrograman, dan menjawab pertanyaan pilihan ganda. Setelah menjawab, pengguna memperoleh umpan balik serta dapat melihat skor dan pembahasan untuk membantu memahami jawaban.
Fitur Aplikasi
1. Halaman awal dan profil pemain — mengisi nama, memilih avatar/karakter, dan menentukan mode permainan.
2. Pemilihan misi — tersedia empat misi utama:
   - Selamatkan Presentasi
   - Detektif Jadwal
   - Kunci Ruang Lab
   - Kuis Pilihan Ganda
3. Maraton 16 Puzzle — pilihan untuk mengerjakan rangkaian puzzle dari beberapa misi.
4. Dua mode permainan — Santai dan Tantangan. Mode Tantangan memiliki penghitung waktu.
5. Interaksi puzzle dan kuis — memilih jawaban, menyusun atau mengurutkan langkah sesuai tipe soal, lalu mengirim jawaban.
6. Petunjuk dan bantuan audio — petunjuk tersedia pada soal tertentu dan antarmuka menyediakan kontrol audio.
7. Feedback jawaban — menampilkan respons saat jawaban benar atau belum tepat.
8. Skor dan progres — menampilkan poin, progres puzzle, combo, persentase akurasi, serta jumlah petunjuk yang digunakan.
9. Hasil dan pembahasan — melihat rangkuman hasil permainan dan meninjau pembahasan jawaban.
10. Mode latihan — mengerjakan latihan dan melihat hasilnya.
11. Lanjutkan permainan atau main lagi — antarmuka menyediakan alur untuk kembali melanjutkan atau memulai permainan kembali.
12. Light/Dark Mode dan layout responsif — tampilan disiapkan untuk mode terang/gelap serta ukuran layar tablet dan landscape.
